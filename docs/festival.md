# 夏日花火大会（第三个测试场景）

打开 `res://scenes/festival.tscn`，按 **F6** 运行当前场景。也可以：

- 在等距测试场里走进下方的 **花火之门**（见下文）。
- 在任意测试场景按 **Esc**，从场景列表里选「夏日花火大会」。

测试场景的顺序是：月下庭院 → 等距测试场 → 夏日花火大会 → 3D 分类试验场。

## 场景

这是一个夜晚的 HD-2D 海港。镜头在山坡露台的远处，一群人站在露台上等着看烟花，**都背对镜头、朝右上方 45° 望向夜空**：

- 前排靠着栏杆：画面中间偏左的一对恋人，旁边是一对老夫妻、几个年轻人和孩子，还有一只背对镜头坐着、望向夜空的小猫。
- 中间：一家三口、跑开的孩子。
- 前景：画面左右两边离镜头近的几个人。

人物脚下是柔和的椭圆影子，比脚宽、中间接触的地方更深；素材每帧脚下留的透明行已经裁掉，人踩在地上，不会飘。

路人大部分时间望着前方，不时把头再往右转一点；每个人的动作错开，不会整齐划一地动。小猫是戴红项圈的黑白奶牛猫：素材里只有它有背面坐姿，会不时把头往右转、甩甩尾巴。

- 头顶的绳子上挂着一串红白相间的灯笼，轻轻摇晃。
- 草地上飘着萤火虫，栏杆边开着发光的铃兰。
- 远处是港口里的帆船、海面、远山和满天星星；右边是灯火通明的对岸城市和灯塔，正好在众人望着的方向。

画面上下有移轴模糊和暗角，和等距测试场的 HD-2D 后期相同。

## 操作

- **放烟花**（屏幕下方的按钮，或按空格）：开始一场烟花大会，约 37 秒。
  - 打开场景后，烟花要先在后台渲染约 2 秒，左上角显示「烟花准备中 n / 14」，期间按钮是灰的。
  - 放烟花期间按钮显示「观赏中」，结束后可以再放一次。
- **Esc**：暂停并打开测试场景列表。

## 烟花大会的运镜

镜头顺着众人的视线走：烟花都在人群望着的右上方夜空里绽放，从远处对岸城市的楼群后面升起。

1. **升起**（约 3.8 秒）：镜头往右上方升起，一边升一边转向右边、仰起，越过人群和灯笼串，看向右上方的夜空。第一枚礼花弹在镜头快升到位时升空。
2. **看烟花**：镜头停在高处仰望，缓缓左右摇；对岸城市在画面下方，礼花弹从屋顶上方冒出来。烟花分成远近三层：近处的（离参考镜头 92～105 米）大、炸得高；远处的（160～190 米）小、低、贴着地平线，颜色也淡一些、略偏冷，像隔着一层夜雾，照亮场景的闪光也弱一些。12 种烟花依次绽放，顺序是：
   1. 球形
   2. 垂柳、圆环
   3. 心形
   4. 十字分裂、千轮
   5. 土星
   6. 棕榈、笑脸
   7. 频闪
   8. 星形、碎裂
3. **压轴**（第 16 秒起）：镜头落到人群后方、往下压、视野拉宽。前排人群的背影在画面下方，中间是灯笼串和港口，上方是空中和岸边的连发。
   - 对岸海边：两座礼花筒扇形齐射。
   - 空中：球形、垂柳、碎裂、心形连发。
   - 最后一发：「烟花·文字绽放」在近处炸开成一行又大又粗的「Jeff Studio」，在空中停约 9 秒，由白金慢慢变成粉色，最后碎成小点熄灭。
4. **落回**（约 3.6 秒）：所有烟花都放完、再停 1 秒后，镜头落回待机的位置。

每发烟花炸开时有两种照明：

- 炸点周围亮起一团平滑的柔光，颜色取自这发烟花的主色。
- 夜空、远景、草地、栏杆和人物被同色的光照亮一下，然后很快暗下去。

## 素材和搭建方法

**素材**：角色、远景、草地、铃兰和按钮上的烟花筒图标，都来自《铃兰之剑》的游戏素材，版权属于原作者。

- 素材放在 `assets/convallaria/`，只在本机测试用。`.gitignore` 已经排除这个文件夹，不要上传或随插件发布。
- 来源和每个文件的内容见 `assets/convallaria/README.md`。
- 缺少这些素材时，场景只显示夜空、灯笼、萤火虫和烟花，左上角会给出提示。
- 运行时直接读取 PNG，不经过导入。导入设置用在 3D 里会把贴图压缩，像素就不清晰了。
- 灯笼、萤火虫、栏杆是代码生成的。夜空、远景层和草地的着色器在 `assets/festival/`，可以正常提交。

**分层远景**：远景来自一张登录画面的贴图集，切成 6 层：天空、远山、海面、对岸城市、港口船只、近处城市。

- 每层是一块平面，面向 **参考镜头**（人群后方远处、略高、向下 9°，也就是待机时的镜头）。
- 先在参考镜头的画面里定好它的位置和大小，再按这一层离镜头多远换算到三维里。
- 所以参考镜头下 6 层拼成一幅完整的画；镜头升起或后拉时，近的层移动得多、远的层移动得少，产生视差。
- 天空、远山、海面左右各镜像延伸两倍宽，镜头往右摇得很远时两边也不会露空。
- 两层城市贴图的右端是切开的，这里设了右端渐隐（`fade_side`），镜头往右摇时城市淡入海面，看不到切边。
- 两层城市比登录画面里的位置往右挪了（对岸城市挪得多一些），让城市落在众人视线的方向、烟花的正下方。
- 露台的草地和栏杆左右铺得很宽（草地 80 米、栏杆 60 米），镜头往右摇、压轴时都看不到露台的尽头。

**透明物体的先后顺序**：按固定顺序绘制，和远近无关：

天空 → 远山 → 海面 → 空中的烟花 → 对岸城市 → 岸边的烟花 → 船 → 近处城市

空中的烟花离参考镜头 116~130 米，在对岸城市（62 米）后面，发射点藏在对岸城市的楼群后面，所以礼花弹是从城市的屋顶上方冒出来的。

## 修改

所有设置都在 `scripts/festival.gd` 顶部的常量里：

| 常量 | 内容 |
|---|---|
| `REF_POS`、`REF_PITCH`、`REF_FOV` | 参考镜头（待机时的镜头） |
| `GAZE_YAW` | 众人视线的方向（参考镜头正前方往右偏多少度）：烟花在这个方向绽放，看烟花的镜头也转向这里 |
| `SKY_*`、`FINALE_*` | 看烟花的镜头、压轴时的镜头（位置相对参考镜头；`FINALE_YAW` 是压轴时的朝向） |
| `CRANE_UP`、`CRANE_DOWN` | 镜头升起、落回所用的秒数 |
| `LAYERS` | 远景各层：离镜头多远、在参考画面里的位置、缩放、绘制顺序、亮度、被烟花照亮的强度 |
| `SHOW` | 节目单：每发的发射时刻、预设、位置、远近、大小；循环播放的烟花（例如地面喷泉）要用 `hold` 指定放多久。节目单里最晚放完的那一发结束、再过 `SHOW_TAIL` 秒，镜头才落回 |
| `NEAR_DEPTH`、`FAR_DEPTH`、`FAR_DIM` | 烟花远近层次：从多近到多远逐渐变暗，最远处的亮度 |
| `BAY_Y`、`FW_PIXEL` | 空中烟花的发射高度、烟花每个像素在世界里多大（米） |
| `CHARACTERS` | 人物和小猫：用哪套帧、站在哪里、动作快慢、影子大小 |
| `LOOK` | 路人的背面帧顺序（正背面 / 头往右转） |
| `LANTERN_*` | 灯笼串的位置、下垂程度、个数、像素图案和颜色 |

**节目单的位置**：每发烟花先在参考画面里定位（x 以画面中间 950 为中心），再绕参考镜头整体转 `GAZE_YAW` 度，转到众人望着的右上方。想让烟花换个方向，只改 `GAZE_YAW`，看烟花的镜头会跟着转。

**节目单里的烟花** 就是插件的「烟花系」预设（`firework_` 开头），在工坊里改了参数，这里也跟着变。

场景里渲染烟花时，会关掉每款烟花自带的「光源」图层。这个图层是照亮夜空的一大团点阵光，在工坊的 2D 画布上很好看，放大到三维天空里会变成一块方形的网点。这里改由场景自己画柔光和闪光，工坊里的预设本身不变。

## 等距测试场里的花火之门

等距测试场下方石板广场的出口处，有一座通往这里的 **花火之门**：

- 地上是传送阵（Codex 三维效果「传送法阵」）。
- 两侧各一座「烟花·地面喷泉」，一直在喷金色火花。
- 门前写着「前往夏日花火大会」。

走进门里会发生这些事：

1. 角色定住，脚下升起「传送光柱」。
2. 门的上空炸开一发「烟花·球形绽放」。
3. 角色淡出，画面变暗，进入夏日花火大会。

门的位置和大小在 `scripts/iso_lab.gd` 的 `GATE_POS`、`GATE_RADIUS`。
