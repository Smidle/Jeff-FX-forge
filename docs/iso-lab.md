# 等距测试场（路线 A）

打开 `res://scenes/iso_lab.tscn`，按 **F6** 运行当前场景。月下庭院（F5）和 3D 分类试验场不受影响。

石板广场下方的出口处有一座 **花火之门**：两侧喷着烟花，门前写着「前往夏日花火大会」。走进去就会传送到第三个测试场景，见 [夏日花火大会](festival.md)。

场景是 3D 的，镜头斜向下看。现有像素角色「姐夫」和山贼木桩以面向镜头的平面贴图出现，站在用《八方旅人》场景素材搭的「林间遗迹 · 山贼营地」里：中间是石板广场，四周有断柱、壁画断墙、营地帐篷、瞭望塔和树林。

## 布景

布景由 `scripts/iso_stage.gd` 搭建。在编辑器里打开 `scenes/iso_stage.tscn` 就能直接看到，不用运行。生成的节点不会保存进场景文件。

**素材**：模型和贴图在 `assets/octopath/`，是《八方旅人》《八方旅人 2》的版权素材，只在本机测试用。`.gitignore` 已经排除这个文件夹，不要上传或随插件发布。来源和导入设置见 `assets/octopath/README.md`。地面的草地、泥土贴图是另外生成的（`assets/iso_stage/`），可以正常提交。

**调整布景**：所有摆放都在 `iso_stage.gd` 顶部的表里，改表就行：

| 表 | 内容 |
|---|---|
| `MODELS` | 用到的模型：名字 → FBX 和其中的子网格 |
| `LAYOUT` | 每个物件的位置、朝向、缩放、是否挡路 |
| `TREE_RING`、`BACKDROP` | 外圈树林和远山（拉远镜头才看得到） |
| `SCATTER` | 随机散布的草、花、碎石数量和范围 |
| `PATHS`、`PATCHES`、`STONES` | 地面上的泥土小路、空地和石板广场 |
| `LIGHTING` | 三种光照预设 |
| `FIRES` | 火盆、篝火、火把上的火 |

火盆、篝火、火把上的火焰用的是插件自带的「篝火」「火把」像素特效，并带有闪烁的火光。

**走动范围**：x 在 -11～11.5、z 在 -9.2～9.8 之间，柱子、帐篷、马车等物件会挡路（`LAYOUT` 最后一项设定挡路范围）。

## 两类效果在这里怎么播放

| | 三维配方（Codex 制作 + Claude 追踪飞弹） | Claude 制作的像素特效 |
|---|---|---|
| 形式 | 真 3D 实例（`JeffForge3DInstance`） | 运行时渲染像素帧，以平面贴图播放 |
| 贴地效果 | 平铺在地面上，有真实透视 | 面向镜头的平面 |
| 有方向的效果 | 从角色朝木桩发出 | 按屏幕方向渲染（取 45° 的倍数） |
| 飞行类效果 | 直线飞向木桩 | 直线飞向木桩 |
| 跟随效果 | 挂在角色身上 | 挂在角色身上 |

放置规则：追踪飞弹从角色胸口发射并持续追踪木桩；其他飞行类效果从角色身前直线飞向木桩（见下面「飞行类效果」）；跟随类挂在角色身上；分叉电弧、渐细流光这类带起终点的效果，从角色胸口连到木桩；有方向的效果从角色朝木桩发出；其余放在木桩那里。

**高度怎么定**（状态栏最后一项会显示实际放在哪里）：

- Codex 制作的三维效果本身就是按脚底原点制作的（命中类已经做在 0.65～1.3 米的身体高度），直接放在脚底。
- Claude 制作的像素特效按自己的画面分布自动判断：
  - **身上**（离地 0.8 米）：围绕中心画的，例如刀光、命中、爆炸、护盾、蓄力、冰晶爆裂、烟雾弹。
  - **脚底**：从底部往上画的，例如篝火、火把、落雷、治疗、传送光柱、消散。小型爆炸、大型爆炸、烟雾弹的升级版原点就在地面上，但地面冲击环和尘浪伸到原点下方较多，自动判断会误判成「身上」，所以单独列在 `PIXEL_FEET` 里直接放在脚底。
  - **脚底贴地**：贴地但有立体部分，例如增益光环、落水水花、召唤阵展开、扬尘、拾取闪光。抬到最低的像素刚好着地，不会被地面挡住。
  - **平铺地面**：魔法阵、地面冲击波。平铺在地上并还原成正圆，角色站在圆里，会挡住圆环。

像素特效的贴图按透明度混合（角色贴图仍是透明裁切）。柔光、叠加光、半透明烟雾这些不到一半透明度的像素因此能显示出来，和工坊预览一致；以前这些像素会被整个裁掉。

## 飞行类效果

奥术飞弹、飞剑剑气、暗器破空（Codex 制作）和火球弹、魔法飞弹（Claude 制作）本身在原地循环播放，设计上由游戏去移动。测试场替游戏把它们飞出去：

- 从角色身前沿直线飞向发射那一刻木桩的位置，不追踪。木桩移动时会落空。
- 速度 7 米/秒。暗器只在前 0.3 秒可见，所以按 18 米/秒飞。
- 到达后：循环的三维效果停止循环，尾迹和留在空中的碎光自然消散；暗器停在木桩处播完；像素贴图直接消失。不另加命中效果。

暗影侵蚀虽然也归在「远程发射」里，但说明写的是诅咒或暗系命中，所以直接出现在木桩身上。

速度和这两条特殊处理在 `scripts/iso_lab.gd` 顶部的 `PROJECTILE_SPEED`、`PROJECTILE_SPEEDS`、`HIT_AT_TARGET`。

## 追踪飞弹

列表里标着「追踪」的四款（御剑流光、火球术、寒冰箭、暗影箭）已并入插件，来源是 Claude 制作，子类是「追踪飞弹系」，在工坊里可以预览并编辑路径，见 [追踪飞弹](missiles.md)。

测试场默认使用「测试场调整」参数（上方下拉框可切回「插件原版」对比），插件内置配方不变：

| 飞弹 | 像素密度 | 飞行时长 | 拖尾长度 | 拖尾宽度 |
|---|---|---|---|---|
| 御剑流光 | 64 → 24 | 0.8 → 0.95 秒 | 1.4 → 2.0 米 | 0.10 → 0.12 米 |
| 火球术 | 64 → 24 | 0.85 → 1.0 秒 | 1.1 → 1.6 米 | 0.18 → 0.20 米 |
| 寒冰箭 | 64 → 24 | 0.65 → 0.8 秒 | 1.55 → 2.2 米 | 0.085 → 0.12 米 |
| 暗影箭 | 64 → 24 | 0.9 → 1.05 秒 | 1.35 → 1.9 米 | 0.15 → 0.17 米 |

原因：测试场的角色每米约 26 个像素，飞弹原来是每米 64 个像素，像素比角色细一倍多，风格不统一；细拖尾在这个距离下还会断成虚线。原配方按 4 米距离设计，测试场约 5 米，所以拖尾加长、飞行稍慢。御剑流光的弹头另外从 0.85 米放大到 1 米，剑在这个距离下更清楚。数值集中在 `scripts/iso_lab.gd` 顶部的 `MISSILE_TUNING`。

四款飞弹的拖尾造型、拖尾粒子和残影见 [追踪飞弹](missiles.md) 的「拖尾、粒子和残影」。

播放时调用 `FX3D.spawn_to()`，从角色胸口发射，一直追到木桩胸口高度，木桩移动时也会追。勾选「木桩移动」可以测试追踪效果。站到木桩下方再释放，可以检查朝远处飞时的画面（见 [追踪飞弹](missiles.md) 的“镜头补偿”）。

## 操作

默认设置：低角度 2.5D 20°/0°、透视镜头、像素化关、像素特效大小 2×、飞弹用测试场调整、傍晚、HD-2D 后期、木桩静止。要改默认值，修改 `scripts/iso_lab.gd` 顶部的 `DEFAULTS`。

- WASD／方向键：按屏幕方向移动；J：普攻（角色动画自带刀光，不再叠加特效刀光）
- 左侧列表：单击一个技能，把它绑定到按键 **1**（单击本身不释放）；上方会显示“按键 1：技能名”
- **1**：释放绑定的技能，可以连按
- **Esc**：打开菜单并暂停。第一项「清除场上效果」就是原来 Esc 的功能（按 Esc 后直接回车即可）；下面可以切换到月下庭院、夏日花火大会或 3D 分类试验场；再按 Esc 继续
- 上方：镜头角度（标准等距 30°/45°、试验场 35°/22°、低角度 20°/0°）、正交／透视、像素化 1×／2×／3×、像素特效大小（只影响 Claude 制作的像素特效，三维特效和追踪飞弹不变）、飞弹参数（测试场调整／插件原版）、光照、后期、木桩移动
- 滚轮：缩放（拉到最远能看到外圈树林和远山）

## 光照和后期

**光照**：傍晚（暖色斜阳，影子长）、白天、夜晚（月光 + 火光）。看发光类特效建议用夜晚。角色贴图不受场景灯光影响，会跟着换一个色调。

**后期**：「HD-2D」是画面上下两条移轴模糊、暗角、泛光、调色和飘浮的光点（傍晚是尘埃，夜里是萤火）；角色在画面中间，始终清晰。想看特效本身的样子就选「关」。移轴模糊和暗角在 `assets/iso_stage/hd2d_post.gdshader`，泛光和调色在 `iso_stage.gd` 的 `_build_environment()`。

泛光在兼容渲染器里是按亮度阈值生效的：特效越亮越容易出光晕。

尺寸换算：角色约 45 像素高，对应约 1.7 米；像素效果与角色的大小比例沿用庭院里的设置（效果 1.5 倍，角色 3 倍）。
