# 1.0 测试清单

按顺序做，每一步后面是「应该看到什么」。哪一步不对，记下步骤编号，最好附一张截图；
Godot 底部「输出」面板里有红字的话，把红字也复制下来。

## 准备

1. 用 Godot 4.7 打开工程（双击 `project.godot`）。第一次打开会导入几秒钟。
2. 点编辑器顶部的 **「特效工坊」** 标签。
   → 左边预设库的缩略图一个个出现，中间在播放，右边是参数。

## A. 浏览和预览

3. 预设库的分类下拉框分别选「魔法与状态」「环境与通用」。
   → 各有 8 个预设。
4. 依次点：火球弹、护盾、魔法阵、召唤阵展开、落地尘土、落水水花、传送光柱、冲刺残影。
   → 都能播放。循环的（火球弹、护盾、魔法阵）一直转，看不出接缝；一次性的播完停一下再重播。
5. 搜索框输入「火」。
   → 只剩名字或说明里带「火」的预设。清空后恢复。
6. 预览区：滚轮缩放、按住中键拖动、双击复位；背景换成「浅色」；勾选「网格」「锚点」。
   → 放大后有像素网格，红色十字在特效原点。
7. 时间轴：空格暂停 / 播放，← → 逐帧，点下面的帧缩略条。
   → 跳到对应的帧。

## B. 调参数

8. 打开「火焰斩」。方向组点「←」，配色主题换成「冰霜」。
   → 刀光朝左、变成蓝色。
9. 「尺寸档」点「大」，再点「中」。
   → 先整体变大（状态栏尺寸翻倍），再恢复。
10. 按 Ctrl+Z 几次。
    → 一步步撤销回去。
11. 打开「重击」，看播放。
    → 第一帧白色闪光停得明显比其他帧久（打击停顿）。
12. 在「画布与时间」里把「打击停顿帧」改成 0。
    → 停顿消失；「停顿倍数」这一项跟着隐藏。改回 1。
13. 图层区：点「添加图层」选「粒子」；试试上移、下移、复制、删除、眼睛隐藏、改图层名。
    → 预览跟着变；Ctrl+Z 能撤销。

## C. 色板编辑器（新功能）

14. 外观组「主色板」右边的 ✎ 按钮。
    → 弹出「编辑色板」窗口，上面是当前色阶的色块。
15. 点「生成」（默认蓝色、6 个颜色），再点「使用这个色板」。
    → 特效变成这组蓝色；「配色主题」显示「自定义」。
16. 再打开编辑器：点一个色块改颜色、点 × 删一个、点 + 加一个、点「按亮度排序」。
    → 色块和下面的预览条跟着变。
17. 导入色板文件：到 lospec.com/palette-list 随便下载一个 `.hex`（或者用 Aseprite 导出的 `.gpl`、一张调色板 PNG），
    点「选择文件…」选它。
    → 下面出现这套色板的所有颜色；点某个颜色加到色阶末尾；点「挑 6 个当色阶」自动挑选；最后「使用这个色板」。
18. 按 Ctrl+Z。
    → 色板恢复成上一步的样子。

## D. 保存和右键菜单（新功能）

19. 点「另存为…」，名称写「我的冰火斩」，保存。
    → 预设库「我的预设」里出现它，缩略图是它画面最饱满的一帧。
20. 在预设库里**右键**它 → 重命名… → 改个名字。
    → 名字变了。
21. 右键 → 复制一份。
    → 多出一个「（副本）」。
22. 右键 → 在文件系统中显示。
    → 编辑器左下角的「文件系统」面板定位到 `fx_forge_presets` 里的这个文件。
23. 右键副本 → 删除… → 确认。
    → 副本从预设库消失（文件在 Windows 回收站里，可以还原）。
24. 右键任意一个内置预设 → 复制为我的预设。
    → 「我的预设」里多一个「（我的）」。

## E. 导出

25. 打开「火焰斩」，点「导出精灵图…」。勾选「GIF 动图」，GIF 放大选 3×，背景选「深色底」，点「导出」。
    → 弹出导出结果；`fx_exports` 文件夹里多了 `slash_fire.gif`，用浏览器打开是会动的放大动图。
26. 同一个预设再导出一次。
    → 先提示会覆盖哪些文件，确认后导出成功。
27. 方向批量选「4 方向」再导出。
    → 精灵图变成 4 行（右、下、左、上）。
28. 打开「重击」导出，然后在 Godot 文件系统里双击 `fx_exports/hit_heavy_frames.tres`。
    → 底部 SpriteFrames 面板里，第 1 帧的时长是 3（打击停顿），其他帧是 1。

## F. 在游戏里

29. 按 **F5** 运行演示场景：鼠标左键点哪里，特效就在哪里播放，滚轮切换特效。
    → 38 个特效都能播放；一次性特效播完自动消失；循环特效一直播放；像素清晰不模糊。
30. （可选）放进你自己的游戏：把 `fx_exports` 里同名的 `.png`、`_frames.tres`、`.tscn` 复制过去，
    用 README「在你自己的游戏里使用」那两行代码生成特效。

## G. 手册

31. 打开 `docs/manual.md`（在 GitHub 网页上看排版最好），看看说明有没有看不懂的地方。

## 反馈时最有用的信息

- 哪个特效不好看：截图 + 说哪里不对（太小、太暗、颜色怪、动作别扭……）。
- 哪个参数看不懂、找不到。
- 哪一步出错：步骤编号 + 「输出」面板里的红字。
