# Jeff FX 1.0.1 · 兼容性与已知限制

## 支持与实际验证

| 项目 | 状态 |
|---|---|
| Godot | 面向 4.7；已实测 4.7.2 |
| 系统/设备 | macOS、Apple M4 |
| 实际画面 | Compatibility 渲染器，正交与透视 |
| 其他平台 | Windows、Linux、Forward+、Mobile 与手机实机未完成本版画面/性能验收 |

已检查内置预设读取、参数修改、导出、首次导入、场景放置与取消、撤销重做及运行播放；这些检查不等于全部美术表现均已完善。发布目录另外做干净工程安装验证。

## 已知表现限制

- 像素工坊的“小型爆炸”“大型爆炸”“毒气爆炸”“烟雾弹”在末帧仍可能保留明显烟火块，接空白时有截断感；选用前逐帧检查。
- 像素工坊与经典库的细节密度不同；配合游戏角色尺寸、背景和摄像机距离调整。
- 经典持续效果录制固定时长，不保证无缝循环；烘焙成二维帧后也不再保留真实三维视差。
- GIF 仅支持全透明/不透明；对半透明柔光使用点阵近似。游戏素材以 PNG 为准。
- 三维面向镜头的层有朝向约束，X/Y 旋转不会像固定网格那样改变正面观察结果；对称形状也可能使旋转不易辨认。
- 一些程序效果在多实例并发时 CPU 成本较高；精简档用于减少装饰，不能代替目标设备实测。优先烘焙不会改变的视觉。
- 放置使用世界 Y=0 平面，没有地形射线探测；也不提供碰撞、伤害、角色按键绑定或技能逻辑。
- 撤销/重做使用 Godot 的编辑历史，可能同时涉及其他全局编辑操作。

## 文件依赖

直接放置的效果、可编辑配方依赖 `addons/fx_forge`。导出的二维即用场景可以脱离插件，但仍需其 PNG 和 SpriteFrames；导出配方副本不属于独立运行文件。

升级请完整替换插件目录，保留个人配方与场景。仓库包含插件、庭院测试工程及用户说明；Release 的专用插件 ZIP 只包含 `addons/fx_forge/`。第三方演示角色和字体的许可单独说明，见 [NOTICE](../NOTICE.md)。开发工具、测试输出、旧场景和个人预设不在发布文件中。
