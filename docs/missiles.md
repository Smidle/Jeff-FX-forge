# 追踪飞弹

四款带拖尾的三维追踪飞弹，来源是 **Claude 制作**。它们来自旧版 Jeff Studio 特效插件，飞行、拖尾、命中的运行代码已经包含在当前插件里，这次把配方、预览和路径编辑器一起并入。

四款都在子类「追踪飞弹系」里。

| 飞弹 | 元素 | 特点 |
|---|---|---|
| 御剑流光 | 物理 | 钢色剑身配金色剑格，剑穗随飞行摆动，剑身带一圈冷光；流光拖尾，带三道剑形残影和十字剑光；命中「剑光星爆」 |
| 火球术 | 火 | 翻卷火核外面一团闪动的火光；两股被气流撕扯的焰旋；身后掉出一团团火团，边飘边冷却成半透明的烟，火星往上飘；命中「火球爆燃」 |
| 寒冰箭 | 冰 | 棱面冰晶箭，箭尖一团冷光；点阵寒气和断续霜线；冰晶、雪花悬在空中飘落；命中「冰晶迸裂」 |
| 暗影箭 | 暗 | 紫黑箭核，边缘暗焰闪动，带一团紫光；交错影带；往后飘散、上缘透着紫光的半透明暗烟和紫色余烬；命中「暗影裂爆」 |

2026-11-01 按 pixelfx 的做法升级了这四款：弹头加了光，火球和暗影箭的拖尾粒子换成会冷却、会散开的烟，命中换成用像素引擎画的「像素命中」（见下文）。飞行轨迹、路径编辑和追踪的设置都没有改。

配方位置：`addons/fx_forge/legacy/presets/missile_*.tres`。

## 拖尾、粒子和残影

飞弹身后的效果由三部分组成，在参数面板里分别调整：

- **拖尾造型**：贴着飞行路线的拖尾。原有 6 种（流带、丝线、碎光、焰流、霜线、影雾），新增 3 种：
  - **焰旋**：火球后面一小段火舌，加两股绕飞行方向旋转的火焰，转到前面的一股亮、转到后面的一股暗；越往尾部越稀。旋转快慢由「环绕速度」控制。
  - **流光**：细而亮的光带，亮段从弹头往尾部流，尾端碎成光点，两侧偶尔闪光。
  - **冰雾**：淡淡的点阵寒气，加一条断续的霜线。
- **拖尾粒子**（「拖尾粒子数量」0～48，「粒子存留时间」控制留多久）：沿路线留在空中的粒子，出生后不跟着飞弹走。样子跟随弹头造型：
  - 御剑：十字剑光
  - 火球：一团团火团，边飘边由白热冷却成暗红、再变成半透明的烟；少数是往上飘的火星
  - 寒冰：冰晶、雪花和闪点
  - 暗影：往后上方飘、上缘透着紫光的半透明暗烟，和几点紫色余烬
- **残影**（「残影数量」0～6）：沿飞过的路线留下弹头的半透明副本，越远越淡，到达后向弹头收拢。

几点说明：

- 新拖尾的像素格固定在地面位置上，拖尾变长时像素不会滑动。
- 粒子数量和残影数量为 0 时与旧版完全一样，已保存的配方不受影响。
- 拖动时间轴来回看，粒子和残影每次的画面都一样。

**第一次发射会卡一下**：新增的两个着色器第一次用到时要编译。等距测试场里第一次发射约卡 0.3 秒，原来约 0.2 秒；之后不再卡。游戏里可以在加载时先放一次。

## 弹头的光

「弹头光晕亮度」（0～2）：弹头周围一团随飞行闪动的叠加光，把周围照亮，暗色背景下最明显。颜色取配方的主色，光心接近白；到达后随弹头一起熄灭。0 = 不加光，已保存的配方不受影响；四款追踪飞弹都是 1。

## 像素命中

「命中造型」新增四种带「像素」的命中，四款追踪飞弹分别用其中一种：

| 命中造型 | 用在 | 画面 |
|---|---|---|
| 火球爆燃（像素） | 火球术 | 一帧白闪和冲击环；白热的火球胀开、翻滚着冷却成暗红；火团顺着来势往前喷，火星飞散后熄灭；余烬往上飘，半透明的烟慢慢升起 |
| 冰晶迸裂（像素） | 寒冰箭 | 一帧白闪和顺着来势的长短十字星芒；炸点裂出细纹、一圈冰环迸开；冰刺和冰晶碎片翻滚着飞散；寒气团慢慢往下沉，雪花闪点闪烁飘落 |
| 暗影裂爆（像素） | 暗影箭 | 一帧紫白闪光；一颗边缘翻腾着紫焰的黑球胀开、往外喷紫色火舌，又被蚀出窟窿；发光的碎晶飞散，暗烟往上飘；最后四周的暗絮被吸回中心 |
| 剑光星爆（像素） | 御剑流光 | 顺着来势的一道长光和菱形白芯的十字星芒；一圈断开的光弧飞出；白黄色的火花和热屑朝前喷、少量往回溅；几点星光闪烁着熄灭 |

几点说明：

- 它们用像素工坊的引擎画，在预设库「pixelfx 升级版 → 命中反馈」里叫「飞弹命中·……」，可以单独打开看、调参数。改了预设，飞弹打中时也跟着变。
- 命中发生在被打的身上，碎屑和火花在空中飞散后消失，不落到地上。
- **大小**：「命中大小」1 米、像素密度 64 时按预设原样渲染；像素格和弹头一样大（「弹头像素精度」），所以等距测试场把像素密度调到 24 时，命中也是同样大小、更粗的像素格。
- **颜色**：主色板和烟尘色板换成配方主色的色相，「饱和度」照样起作用；白闪和火花的颜色不变。
- **时长**：整段命中拉伸到「命中持续时间」播完（四款默认 0.6～1 秒）。
- **方向**：命中画的是从左边打过来；来势在屏幕上朝左时自动左右翻转。贴图往镜头挪一点，打在目标身上时画在目标前面。
- 选了像素命中时，「命中碎屑数量」「命中朝向」不起作用，面板上会隐藏。
- 发射时就在后台渲染命中帧，飞行途中渲染好；同样的参数只渲染一次，之后的飞弹直接复用。

原来的六种命中（火星、气浪、星爆、爆燃、冰碎、影裂）还在下拉框里，已保存的配方不受影响。

## 在工坊里找到它们

预设库第一个下拉框选 **Claude 制作**，或者用"战斗用途 → **追踪飞弹系**"筛选。想按元素找（火 / 冰 / 暗），在“更多筛选 → 元素”里选。单击打开后，预览区上方会多出一行 **飞弹预览** 工具条。

## 预览

| 控件 | 作用 |
|---|---|
| 目标静止 / 直线移动 / 绕圈 / 横向折返 | 模拟目标运动，检查追踪效果。只影响预览，不保存到配方 |
| 路径辅助线 | 青线是模板路径；黄线是追踪移动目标时每枚飞弹的剩余路径；暖色圆圈是当前目标位置 |
| 参考角色 | 在发射起点放一个约 1.9 米高的角色，用来对照大小 |
| 稻草人 | 在终点放一个稻草人（模拟目标移动时跟着走），飞弹打中时它会做出受击反应，见下文 |

播放、暂停、单步、拖动时间轴都可以用，模拟目标也能来回拖动时间轴重看。

## 终点的稻草人

工坊的飞弹预览里，终点站着一个约 2 米高的像素稻草人：木桩和横杆、麻袋上衣胸口有红色靶环、系绳腰带、麻袋头缝着 X 眼睛和笑嘴、戴一顶草帽。飞弹打中时：

- **闪白**：先两帧纯白剪影，再一帧半白。
- **摇晃**：像装在弹簧上一样被推得往后仰（顺着来势的方向），来回摆几下停住。
- **染色**：按命中的元素染色再慢慢褪掉：火烧黑、冰结霜（还会发抖）、暗影发紫；剑不染色。
- **稻草**：身上飞出几根稻草，在空中飘一会儿就消失。

反应全部按「离命中过了多久」算，来回拖动时间轴，画面每次都一样；多枚飞弹连续打中时反应会叠加。工具条的「稻草人」可以关掉。

游戏里也能用它当测试目标：

```gdscript
const StrawTarget = preload("res://addons/fx_forge/runtime/fx_straw_target.gd")

var target := StrawTarget.new()
add_child(target)
target.position = Vector3(3, 0, 0)
# 飞弹画面上到达时让它挨打：元素 fire / ice / shadow 或空，来势用来决定往哪边仰
effect.arrived.connect(func(_index, _at): target.hit("fire", 1.2, Vector3.RIGHT))
```

做法参考 pixelfx 的弹簧稻草靶（src/core/act.js），造型是重画的，见 `NOTICE.md`。

## 编辑路径

**拖动起点和终点**：预览里的绿色圆点是起点，暖色圆点是终点，左键直接拖。

**自定义曲线**：
1. 点 **转为自定义曲线**，或在参数面板的"飞行轨迹"里选"自定义曲线"。当前的路径（直线、抛物线、螺旋……）会转成一条可编辑曲线，形状保持不变。
2. 拖动带编号的圆点改位置。选中某个节点后，会出现两个小柄，拖动它们调整切线（弯曲方向）。
3. **添加节点**：在选中节点之后插入新节点，曲线形状不变。**删除节点**（或按 Delete）：删掉选中的中间节点。首尾节点跟随起点和终点，不能删。

**限制拖动方向**：工具条选"只沿 X / Y / Z 轴"，或者在预览里按 X / Y / Z 键切换，再按一次取消。

**撤销**：每次完整拖动、转换、加删节点各算一步，可以用编辑器的撤销 / 重做。拖到一半按 **Esc** 放弃这次拖动。

右键拖动转镜头，滚轮缩放，和其他三维预览一样。

曲线的坐标是相对起终点连线的：X 是沿连线的比例（0 是起点，1 是终点），Y 是弧高（米），Z 是侧向偏移（米）。所以改变起终点距离时，曲线会按比例拉长，但弧高和侧移不变。

## 镜头补偿（朝远处或朝镜头飞时不再被压扁）

弹头按真实三维长度沿飞行方向摆放。飞行方向接近镜头视线时（低角度 2.5D 镜头下从屏幕下方往上打，或者朝镜头飞来），它在屏幕上会被压成一小团或一条细线。

现在弹头、魔法环带、消散碎光、元素碎片、拖尾、伴随碎光、拖尾粒子和残影都会自动补偿：屏幕上的长度不低于原长的 85%，深度方向保持真实走向，弹尖仍然落在真实的命中位置。侧向飞行时画面和原来完全一样。

拖尾以弹尖为中心按同样的倍数拉长，所以和弹头的衔接点不变；但拖尾末端不会越过发射点，刚发射时拖尾仍然连回手上，飞出一段后才和角色拉开。

补偿强度在 `addons/fx_forge/legacy/assets/missile_view.gdshaderinc` 里的 `MIN_SCREEN_LENGTH`（默认 0.85，设为 0 即恢复原来的纯三维长度）。改这个值时，`legacy/runtime/fx_missile.gd` 里的 `VIEW_MIN_SCREEN_LENGTH` 要同步改（伴随碎光和残影的位置在 CPU 上计算）。

## 在 2.5D 像素游戏里的参数建议

插件原版的飞弹按每米 64 个像素绘制。如果你的角色像素更粗（例如等距测试场的角色每米约 26 个像素），把飞弹的 **像素密度** 调到接近角色（24），风格才统一；细拖尾也要相应加宽，否则会断成虚线。等距测试场用的一组数值见 [等距测试场](iso-lab.md)。

## 在游戏里使用

```gdscript
const FX3D = preload("res://addons/fx_forge/runtime/fx_3d.gd")
const Classic = preload("res://addons/fx_forge/presets/classic_presets.gd")

func shoot(target: Node3D) -> void:
	var recipe = Classic.find("classic_missile_fireball").legacy_recipe
	# 从枪口发射，追踪目标，打在目标本地坐标 (0, 0.9, 0)
	var effect = FX3D.spawn_to(recipe, get_tree().current_scene, $Muzzle.global_position, target, Vector3(0, 0.9, 0))
	if effect != null:
		effect.arrived.connect(func(index, at): print("第 %d 枚到达 %s" % [index, at]))
```

- `spawn_to` 追踪移动目标；`spawn_between` 飞向固定的世界坐标终点。
- `arrived` 只表示画面上到达，不负责伤害判定，伤害请在游戏脚本里处理。
- 保存为"我的预设"的版本，用 `load("res://fx_forge_presets/xxx.tres").legacy_recipe` 取配方。

等距测试场里按 **2** 可以直接看追踪火球，见 [等距测试场](iso-lab.md)。
