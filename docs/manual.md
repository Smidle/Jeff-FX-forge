> 版本 1.0 · 适用于 Godot 4.7

## 1. 它能做什么

- **38 个内置像素特效**，分四类：战斗打击、爆炸与元素、魔法与状态、环境与通用。
- **每个参数都能调**：大小、粗细、方向、颜色、描边、柔光、帧数、速度……右边的面板会自动列出当前特效的全部参数，每个参数都有中文说明。
- **一键导出**：精灵图 PNG、Godot 动画资源（SpriteFrames）、即用场景（.tscn）、Aseprite 格式 JSON、单帧序列、GIF 动图。
- **导出的场景不依赖插件**：删掉插件，游戏里照样能播放。
- **像素画风格有保障**：所有特效都是在 CPU 上逐像素画出来的，只用色板里的颜色，线条干净、不会模糊。

## 2. 安装与打开

**直接用本工程**：用 Godot 4.7 打开本文件夹里的 `project.godot`，插件已经启用。

**装进你自己的游戏工程**：

1. 把 `addons/fx_forge` 整个文件夹复制到你工程的 `addons/` 目录下。
2. 打开「项目 → 项目设置 → 插件」，勾选「FX Forge 像素特效工坊」。
3. 编辑器顶部（和「2D」「3D」「脚本」并列）会出现 **「特效工坊」** 标签，点它就能打开。

> 你保存的预设放在 `res://fx_forge_presets/`，导出的文件默认放在 `res://fx_exports/`。这两个文件夹都在插件文件夹外面，以后升级插件不会覆盖它们。

## 3. 界面导览

```
┌ 工具栏：新建 · 保存 · 另存为 · 撤销 · 重做 · 换种子 ………………… 导出精灵图… ┐
├──────────┬──────────────────────────────────┬────────────────────┤
│ 预设库    │ 预览区（放大的动画）               │ 参数面板             │
│ 搜索 分类 │                                  │ 预设名称 / 说明       │
│ 缩略图    │                                  │ 画布与时间、方向、     │
│ ……       │ 时间轴：播放 · 逐帧 · 进度 · 帧条   │ 外观、描边、清理       │
│          │ 状态栏：尺寸 · 帧数 · 颜色数 · 耗时 │ 图层列表 + 图层参数    │
└──────────┴──────────────────────────────────┴────────────────────┘
```

- **预设库（左）**：点缩略图打开预设；上面可以搜索、按分类筛选。右键点缩略图有更多操作（见第 8 节）。
- **预览区（中）**：
  - 滚轮缩放，按住中键拖动，双击恢复。
  - 上方可以选缩放倍数、切换背景（棋盘格 / 深色 / 浅色 / 自定义颜色）、显示像素网格（放大到 6 倍以上时）和锚点十字（红色十字 = 特效原点）。
  - 「参考图…」可以放一张你的角色图片在特效后面对比大小（右键拖动它）。
- **时间轴（中下）**：播放 / 暂停（空格）、上一帧 / 下一帧（← →）、拖进度条、点帧条跳到某一帧；「循环预览」让一次性特效播完停一下再重播；可以调预览速度（不影响导出）。
- **状态栏**：画布尺寸、帧数、帧率、动画时长、用了几种颜色、渲染耗时。特效超出画布时会出现「⚠ 特效超出画布」和「自动适配画布」按钮。
- **参数面板（右）**：全局参数在上，图层列表和当前图层的参数在下。参数名旁边的 ↺ 恢复默认值；鼠标停在参数名上看说明。底部勾选「显示高级参数」能看到更多选项。

## 4. 五分钟上手：从挑预设到在游戏里播放

1. 点顶部的 **「特效工坊」** 标签。
2. 左边点 **「火焰斩」**，中间开始播放。
3. 右边拖一拖：
   - 「方向」组的八方向按钮：换个朝向。
   - 「外观」组的「配色主题」：换成「冰霜」试试。
   - 图层「刀光」的「宽度」：刀光变粗变细。
4. 觉得满意，点右上角 **「导出精灵图…」**，直接点「导出」。
5. 按 **F5** 运行演示场景：鼠标左键点哪里，特效就在哪里播放，滚轮切换特效。
6. 想保留这次的修改：点工具栏 **「另存为…」**，起个名字，它就会出现在预设库的「我的预设」里。

## 5. 调参数

### 5.1 全局参数（每个特效都有）

| 分组 | 参数 | 用途 |
|---|---|---|
| 画布与时间 | 尺寸档 小 / 中 / 大 | 一键把整个特效缩小一半、原样、放大一倍（画布一起变） |
| | 画布宽 / 高、整体缩放 | 精细控制画布和整体大小；描边宽度不随缩放变化 |
| | 帧数、帧率 | 帧数 ÷ 帧率 = 动画时长 |
| | 循环 | 打开后最后一帧会无缝接回第一帧（火焰、光环、护盾用） |
| | **打击停顿帧、停顿倍数** | 让某一帧多停一会儿（例如命中闪光那一帧停 3 倍时间），打击感更强。导出的动画、JSON、GIF 都会带上这个停顿 |
| | 随机种子 | 换个数字就是同一特效的另一种随机变化；工具栏「换种子」随机换一个 |
| | 原点 X / Y（高级） | 特效中心在画布里的位置，也是导出场景的定位点 |
| 方向 | 八方向按钮、方向角、水平 / 垂直翻转 | 0° 朝右，90° 朝下，180° 朝左，270° 朝上 |
| 外观 | 配色主题、主色板、辅色板、烟尘色板 | 见第 7 节 |
| | 柔光强度 | 0 = 纯硬边像素；调高后外圈出现分级半透明的发光 |
| | 色阶抖动 | 相邻颜色之间用点阵过渡（2×2 / 4×4） |
| | 消散方式 | 特效变淡时：抖动溶解 / 收缩 / 变暗 / 淡出 |
| 描边 | 描边、宽度、颜色、拐角 | 外描边、内描边、选择性描边（描边颜色跟着旁边像素自动加深） |
| 清理 | 去除孤立像素、最小团块 | 去掉零散的杂点（粒子图层的小点不会被清掉） |

### 5.2 图层参数（每一层都有）

显示 / 隐藏、用哪个色板、开始和结束时间（这一层只在时间轴的一段里出现，例如烟雾从 30% 才开始）、是否跟随全局方向、角度偏移、位置偏移、是否参与描边、这一层自己的消散方式。

### 5.3 模块参数

每种图层（模块）有自己的参数，分「形状」「运动」「细节」三组。只和当前设置有关的参数才显示，例如粒子形状不是「拖影线」时不显示「拖影长度」。

## 6. 图层：一个特效由几层叠成

图层列表里，**上面的图层盖住下面的**。每行右边的按钮：上移、下移、复制、删除；左边的眼睛临时隐藏。点「添加图层」选一种模块，新图层加在最上面。图层名可以改成中文。所有图层操作都能撤销。

| 模块 | 适合做 | 关键参数 |
|---|---|---|
| 弧光 | 刀光、回旋斩、月牙 | 半径、宽度、弧度、尖锐度、拖尾、残影数 |
| 射线爆发 | 打击火花、星形闪光 | 射线数、长度、扩散角、中心闪光 |
| 环 | 冲击波、光环、护盾泡 | 半径、环宽、地面透视（压扁成椭圆）、分段虚线、模式（扩散 / 收缩 / 呼吸 / 静止） |
| 粒子 | 火星、碎屑、尘土、水滴、治疗十字 | 数量、形状（含「烟团」）、发射区域、速度、重力、阻力、寿命；向中心汇聚、左右对称、左右摆动、落地消失 |
| 冲刺线 | 突刺、冲刺、速度线 | 条数、长度、宽度、前冲距离 |
| 能量团 | 爆炸火球、烟团、毒雾 | 团数、半径、翻滚强度、热度、冷却、烧穿消散、上升距离 |
| 火焰 | 篝火、火把（可循环） | 宽、高、底部形状、火舌数、摇曳、湍流 |
| 闪电 | 落雷、电弧、放射闪电 | 模式、长度、锯齿幅度、分支、闪烁次数 |
| 能量弹 | 火球弹、魔法飞弹 | 弹体形状、核心 / 光晕半径、拖尾、环绕光点 |
| 法阵 | 魔法阵、召唤阵、护盾符文 | 环数、星形顶点和跳点（6 跳 2 = 六芒星）、刻度、地面透视、逐笔画出 |
| 光柱 | 传送光柱、激光、圣光 | 长度、宽度、展开 / 收起、流动亮条、底部光斑 |

## 7. 配色与色板编辑器

**配色主题**一次给三个色板换色：主色板（大部分图层）、辅色板（火星、闪光等点缀）、烟尘色板（烟雾、尘土）。每个图层在「图层设置」里选用哪个色板。

**色板**是一条从暗到亮的颜色阶梯：特效最暗的地方用左边的颜色，最亮的地方用右边的颜色。

点色板下拉框右边的 **✎ 编辑按钮** 打开色板编辑器，有三种做法：

1. **逐个改色块**：点色块改颜色；× 删掉；+ 在末尾加一个更亮的颜色；「按亮度排序」「反转」整理顺序。
2. **用一个颜色生成色阶**：选一个颜色、选颜色数（3~8），点「生成」。会得到暗部偏冷、亮部偏暖的像素画常用色阶。
3. **导入色板文件**：点「选择文件…」，支持
   - Lospec 网站下载的 `.hex`（每行一个颜色）
   - GIMP / Aseprite 的 `.gpl`
   - 调色板图片 `.png`（取图里所有不透明的颜色）

   导入后，点任意颜色把它加到色阶末尾；或者点「挑 6 个当色阶」「全部使用」自动按亮度挑选。

点「使用这个色板」后，这个色板槽变成「自定义」，配色主题显示为「自定义」。自定义色板保存在预设里，导出的预设副本也会带上它。

## 8. 保存和管理「我的预设」

- **内置预设是只读的**：改完后点「另存为…」存成「我的预设」（可以用中文名）。之后再改就直接点「保存」（Ctrl+S）。
- 有未保存的修改时，标题前面有 ● ；切换预设或关闭编辑器时会提醒你。
- **预设库右键菜单**：
  - 我的预设：打开、重命名…、复制一份、在文件系统中显示、删除…（删除的文件会移到系统回收站，可以找回）
  - 内置预设：打开、复制为我的预设
- 预设库的缩略图会挑动画里画面最饱满的一帧。
- 双击导出目录里的 `xxx.fxforge.tres`（预设副本）也能回到特效工坊继续修改。

## 9. 导出

点 **「导出精灵图…」** 打开导出对话框：

| 选项 | 说明 |
|---|---|
| 文件名、保存到 | 文件名只能用英文字母、数字、下划线；默认保存到 `res://fx_exports/` |
| 排列 | 自动 / 每个动画一行 / 固定列数；间距、边距 |
| 裁边 | 裁掉所有帧共同的空白，锚点自动换算 |
| 放大倍数 | 1× 给游戏用；2×~4× 适合发图分享 |
| 方向批量 | 不批量 / 左右 / 4 方向 / 8 方向，每个方向导出一个动画 |
| 随机变体 | 用不同的随机种子各导出一份，游戏里随机挑一个播放更自然 |
| 导出内容 | 精灵图 PNG（必选）、JSON、SpriteFrames、即用场景、单帧序列、预设副本、**GIF 动图** |
| GIF 放大、背景 | GIF 单独的放大倍数（默认 3×）；背景可选透明 / 深色 / 浅色。GIF 只有「全透明」和「不透明」两种像素，透明背景时柔光会变成点阵；想保留柔光的样子就选深色或浅色底 |
| 场景混合 | 正常 / 发光叠加（火焰、魔法等发光特效叠在背景上更亮） |

导出的文件：

| 文件 | 用途 |
|---|---|
| `xxx.png` | 精灵图：所有帧拼在一张图上 |
| `xxx_frames.tres` | Godot 的动画资源：帧率、循环、打击停顿都设好了 |
| `xxx.tscn` | 即用场景：自动播放，一次性特效播完自动删除；不依赖插件 |
| `xxx.json` | Aseprite 格式的帧数据，其他引擎和工具能读（每帧时长、锚点、帧率都在里面） |
| `xxx_seq/` | 单帧 PNG 序列，可以在 Aseprite 里打开继续手工修改 |
| `xxx.gif` | GIF 动图，用来预览、发给别人看（只含第一个动画；一次性特效末尾会停顿 0.4 秒再重播） |
| `xxx.fxforge.tres` | 这次导出用的预设副本 |

同名文件重新导出会覆盖（会先问你）；已经存在的 SpriteFrames 会原地更新，游戏里引用它的场景自动用上新效果。

## 10. 在游戏里使用

**最简单的方式：在命中点生成即用场景**

```gdscript
var fx = preload("res://fx_exports/slash_fire.tscn").instantiate()
fx.position = hit_position      # 特效原点放在哪里
add_child(fx)                   # 一次性特效播完会自动消失
```

- **朝左**：把节点的 `scale.x` 设成 -1（锚点不会跑）。场景检查器里也可以勾「随机左右镜像」。
- **循环特效**（篝火、护盾、魔法阵……）不会自动消失，不需要时调用 `fx.queue_free()`。
- **多方向导出**：动画名是 `right`、`down`、`left`、`up` 等，用 `fx.play("left")` 播放对应方向。
- **发光叠加**：导出时选「发光叠加」，场景会带一个叠加混合的材质。
- **打击停顿**：导出的动画已经带上停顿帧的时长，不需要额外代码。
- **其他引擎**：用 `xxx.png` + `xxx.json`（Aseprite 数组格式）。

## 12. 常见问题

**状态栏提示「特效超出画布」**
点旁边的「自动适配画布」，或者调大画布宽 / 高。

**柔光看起来发灰**
柔光是半透明的，在深色背景上会显得偏灰。细线条（法阵、细光丝）柔光调到 0.2 以下更干净；大块发光体（护盾、能量弹）可以到 0.5。

**参数太多找不到**
很多参数默认隐藏：先打开相关开关（比如描边选了「无」，描边颜色就不显示）；不常用的参数在「显示高级参数」里。

**游戏里特效模糊**
导出的场景已经设成最近邻过滤。如果你自己用精灵图，记得把纹理过滤设成 Nearest（最近邻）。

**导出时提示「编辑器正在扫描或导入文件」**
等几秒（编辑器右下角的进度条走完）再导出。

**撤销把我在场景里的修改也撤销了**
工坊的撤销接入了编辑器的全局撤销历史，和 Ctrl+Z 一样按时间顺序撤销。

**想做英文界面**
界面文字都集中经过翻译函数，开发者说明见仓库的 `CLAUDE.md`「多语言」一节。

## 13. 小词典

- **精灵图**：把动画每一帧拼在一张 PNG 上。
- **SpriteFrames**：Godot 存放帧动画的资源。
- **色板**：一组从暗到亮的颜色，像素画只用这几种颜色。
- **描边**：外圈一像素宽的深色轮廓，让特效在任何背景上都看得清。
- **抖动**：用棋盘格点阵在两种颜色之间过渡，像素画常用。
- **原点 / 锚点**：特效的定位点，导出的场景放在哪里，特效就以这个点为中心播放。
- **打击停顿**：命中瞬间让画面停一下，动作游戏常用来增强打击感。
- **循环**：最后一帧无缝接回第一帧，可以一直播放。
